## 🛠️ 工具配置

### 1. 已有工具
- ✅ `summarize` - 网页/文档摘要
- ✅ `memory_search` - 记忆检索
- ✅ `feishu_doc` / `feishu_wiki` - 飞书文档

### 2. 推荐新增
- **memory-curator** - 自动整理记忆
- **chroma** 或 **qdrant** - 向量数据库（大量文档时）

## 📋 使用流程

### 长会话记忆
1. 重要信息 → 自动记录到 `memory/YYYY-MM-DD.md`
2. 关键决策 → 同步到 `MEMORY.md`
3. 定期整理（每周）→ 归档旧记忆

### 项目文档管理
1. 新项目 → 创建 `projects/{project-name}.md`
2. 文档摘要 → 使用 `summarize` 生成概要
3. 协作共享 → 同步到飞书文档

## 🔍 检索方式

| 场景 | 命令/方法 |
|------|-----------|
| 搜索历史记忆 | `memory_search "关键词"` |
| 查找项目文档 | `read projects/xxx.md` |
| 摘要网页/文档 | `summarize "URL"` |
| 飞书文档检索 | 飞书搜索功能 |
