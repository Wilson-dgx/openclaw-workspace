## 技术原理深度

### 皮秒ICCD相机工作原理
1. **光学信号输入**：超快现象图像通过前端光学系统处理
2. **像增强器**：送至ICCD像增强器处
3. **门控控制**：高精度脉冲发生器控制产生选通脉冲信号
4. **时序开门**：依次打开像增强器（时间门控）
5. **信号放大**：图像信息通过像增强器增益放大
6. **传感器捕获**：进入图像传感器保存及处理

**技术优势**：
- 优异的时间分辨率（200ps-500ps）
- 空间分辨率高
- 良好稳定性
- 零噪声探测技术

### 与国外产品对比
- **中智科仪 TRC411 Ultra**：200ps光学门宽
- **德国BEOSYS**：250ps
- **优势**：信噪比提升3倍，当前全球最快之一
