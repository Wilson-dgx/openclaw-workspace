## 📌 核心流程

### 自动进化（每6小时）
- 配置见 `HEARTBEAT.md`
- 搜索 → 评估 → 安装 → 生成报告

### 日志归档
- 当日记录：`memory/YYYY-MM-DD.md`
- 7天后自动清理（仅保留会议/知识）

### 记忆检索
使用 `memory_search` 语义搜索：
- 查询方总偏好/习惯
- 查找会议记录
- 检索历史决策
